# Zhifa Geng Academic Homepage

Personal academic homepage hosted with GitHub Pages.

## Sections

- About
- Research Interests
- Selected Work
- Projects
- Experience
- Technical Stack
- Contact

## Local preview

Open `index.html` directly in a browser, or serve the repository with any static HTTP server.

## Deployment

The site is designed for GitHub Pages on the `main` branch. After reviewing and merging the accompanying pull request, ensure GitHub Pages is configured to publish from the repository root.
